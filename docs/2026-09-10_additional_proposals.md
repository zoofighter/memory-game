## 2. 카테고리 A: 분석 기법 추가

### A1. ⭐⭐⭐ 상관관계 히트맵 (Correlation Heatmap)

**현재 빈 곳**: 실적 테이블은 기업별 숫자를 나열할 뿐, 기업 간 **연동 관계**를 보여주지 않음.

**제안**: 하이퍼스케일러 Capex 증감과 다른 기업 매출 간의 상관계수를 히트맵으로 시각화.

```
              구글Capex  아마존Capex  MSCapex  엔비디아매출  삼성영업이익  SK하이닉스매출
구글Capex       1.00      0.92      0.88      0.95        0.78         0.85
엔비디아매출    0.95      0.91      0.93      1.00        0.82         0.90
삼성영업이익    0.78      0.72      0.75      0.82        1.00         0.88
```

**가치**: *"자본과 기술의 흐름을 읽어낼 수 있을까"* → 상관계수가 **흐름의 강도**를 정량적으로 보여줌. 구글 Capex가 1% 오르면 엔비디아 매출이 몇 % 따라가는지 즉시 파악.

**구현**: DB `financials` 테이블에서 `pandas.corr()` → 히트맵 SVG 생성. 1일 이내 구현 가능.

---

### A2. ⭐⭐⭐ 선행·후행 지표 분석 (Leading vs Lagging Indicators)

**현재 빈 곳**: 모든 데이터가 같은 시점에 나열됨. 어떤 데이터가 **먼저 움직이는지** 모름.

**제안**: 시간차(Time Lag) 분석으로 선행지표를 식별.

| 선행 지표 (먼저 움직임) | 후행 지표 (뒤따라 움직임) | 시차 |
| :--- | :--- | :---: |
| 하이퍼스케일러 Capex 가이던스 | 엔비디아 데이터센터 매출 | 1~2분기 |
| 엔비디아 GPU 수주 잔고 | TSMC 선단공정 가동률 | 1~2분기 |
| TSMC CoWoS 캐파 증설 발표 | SK하이닉스/삼성 HBM 출하량 | 2~3분기 |
| ASML EUV 장비 수주 | TSMC 차세대 공정 양산 시점 | 4~6분기 |
| 어닝콜 내 Capex 가이던스 상향 | 해당 분기 이후 전체 밸류체인 매출 증가 | 1~3분기 |

**가치**: 미래 예측 테이블(아웃풋③)의 **근거 강화**. "ASML 수주가 올랐으니 2년 후 TSMC 양산이 늘어난다"는 인과 추론 가능.

---

### A3. ⭐⭐ 계약 네트워크 중심성 분석 (Contract Network Centrality)

**제안**: 계약 데이터를 **네트워크 그래프**로 분석하여, 어떤 기업이 생태계의 허브(Hub)인지 계량화.

| 지표 | 의미 | 현재 최고 예상값 |
| :--- | :--- | :--- |
| **연결 중심성** (Degree) | 가장 많은 계약 연결을 가진 기업 | 엔비디아 (양측 모두 연결) |
| **매개 중심성** (Betweenness) | 자본 흐름의 병목·관문 역할 기업 | TSMC (파운드리 독점) |
| **근접 중심성** (Closeness) | 생태계 전체에 가장 빨리 영향 미치는 기업 | 구글 (투자+구매 양면) |

**구현**: DB `contracts` 테이블 → Python `networkx` 그래프 분석 → Mermaid 또는 D3.js force-directed 그래프.

---

### A4. ⭐⭐ 기업별 밸류에이션 멀티플 비교

**제안**: 시가총액, P/E, P/S, EV/EBITDA 등 밸류에이션 지표를 실적 테이블에 병행 추가.

| 기업 | 시가총액($B) | P/E | P/S | 의미 |
| :--- | :---: | :---: | :---: | :--- |
| 엔비디아 | $3,200 | 25x | 16x | 시장이 기대하는 성장률 |
| TSMC | $1,100 | 18x | 9x | 상대적 저평가 여부 |
| 삼성전자 | $380 | 7x | 1.4x | HBM4 턴어라운드 반영 여부 |

**가치**: 실적 데이터만으로는 "이 기업이 싼지 비싼지" 판단 불가. 멀티플을 병렬 배치하면 **투자 관점의 인사이트** 확보.

## 3. 카테고리 B: 자동화 & 알림 기능

### B1. ⭐⭐⭐ 어닝콜 자동 요약 파이프라인 (LLM 연동)

**현재 빈 곳**: 데이터 소스 정의서에 어닝콜 트랜스크립트가 소스로 있지만, **수동 읽기**가 전제됨.

**제안**: 분기마다 발표되는 어닝콜 전문을 자동 수집 → LLM(Claude API)에 입력 → 핵심 정보를 구조화된 형식으로 추출하여 `99.raw/`에 자동 적재.

```
[입력] 엔비디아 2026 Q2 어닝콜 트랜스크립트 (3만 자)
         ↓ Claude API
[출력]
- Capex 가이던스: $8.5B (전분기 대비 +15%)
- HBM4 언급: "삼성전자 HBM4 퀄 통과, 2개 공급사 체제"
- Rubin 출하: "Q3 초기 샘플 출하 시작"
- 위험 요인: "CoWoS 캐파가 여전히 타이트"
         ↓ 자동 저장
99.raw/financials/2026_Q2_nvidia_earnings.md
99.raw/milestones/2026_Q2_nvidia_guidance.md
```

**가치**: 분기마다 16개사 어닝콜을 수동으로 읽는 건 비현실적. LLM 자동 요약으로 **데이터 투입 속도 10배 향상**.

---

### B2. ⭐⭐⭐ 뉴스 알림 & 자동 분류 봇

**제안**: Google News RSS를 주기적으로 폴링하여, 추적 대상 기업의 **중대 계약/실적/기술 뉴스**를 감지하면 자동으로:
1. 중요도를 분류 (CRITICAL / HIGH / MEDIUM)
2. 관련 기업 태깅
3. `99.raw/` 해당 디렉터리에 초안 자동 생성
4. (선택) 슬랙/텔레그램/이메일 알림 발송

```
[감지] "구글, 앤트로픽에 추가 500억 달러 클라우드 크레딧 제공"
  → 중요도: CRITICAL
  → 기업: GOOGLE, ANTHROPIC
  → 자동 생성: 99.raw/contracts/2026_google_anthropic_v2.md
  → 알림: "🔴 CRITICAL 계약 감지 — 구글-앤트로픽 추가 계약"
```

---

### B3. ⭐⭐ 데이터 신선도 대시보드

**제안**: 각 기업의 데이터가 마지막으로 업데이트된 시점을 추적하여, **오래된 데이터를 경고**.

```
| 기업 | 실적 마지막 업데이트 | 계약 마지막 업데이트 | 상태 |
| 구글 | 2026-07-25 (45일 전) | 2026-08-30 (10일 전) | ⚠️ 실적 갱신 필요 |
| 삼성전자 | 2026-08-15 (25일 전) | 2026-06-01 (100일 전) | 🔴 계약 오래됨 |
| 앤트로픽 | 2026-03-01 (190일 전) | 2026-02-15 (200일 전) | 🔴 전체 갱신 필요 |
```

## 4. 카테고리 C: 시각화 확장

### C1. ⭐⭐⭐ 자본 흐름 애니메이션 (Animated Capital Flow)

**현재 빈 곳**: Sankey Diagram은 **한 시점의 스냅샷**만 보여줌.

**제안**: 2024 → 2025 → 2026 → 2027(예측) → 2028(예측)으로 **시간이 흐르면서 자본의 줄기가 굵어지거나 가늘어지는 애니메이션**. 

- 2024년: 구글→앤트로픽 자본선이 가늘다가
- 2026년: 2000억$ 계약으로 **폭발적으로 굵어지는** 시각적 임팩트
- 자동 재생 또는 슬라이더 드래그

**가치**: human.md의 *"메모리와 반도체 섹터 그리고 ai 프론티어 모델을 둘러싼 거대한 투자와 혁신의 게임"* → 이 "게임"의 역동성을 **체감**할 수 있는 가장 강력한 시각화.

---

### C2. ⭐⭐ 지리적 공급망 지도 (Geospatial Supply Chain Map)

**제안**: 세계 지도 위에 기업·시설의 물리적 위치를 표시하고, 부품·자본 흐름을 곡선으로 연결.

```
🇺🇸 실리콘밸리 (엔비디아 본사) ←──GPU 설계──→ 🇹🇼 대만 신주 (TSMC 파운드리)
                                                    ↓ CoWoS 패키징
🇰🇷 이천/청주 (SK하이닉스 HBM) ──────HBM 납품──→ 🇹🇼 대만 (TSMC 조립)
                                                    ↓ 완성 GPU
                                           🇺🇸 전국 (하이퍼스케일러 DC)
```

**가치**: 지정학적 리스크(대만 해협 긴장, 미중 기술 전쟁) 시 **어떤 경로가 끊기는지** 직관적 파악.

---

### C3. ⭐⭐ 기업 간 파워 밸런스 레이더 차트

**제안**: 특정 기업을 선택하면 5개 축으로 **생태계 내 영향력**을 레이더 차트로 표시.

5개 축 예시 (엔비디아):
1. **매출 지배력** (데이터센터 GPU 점유율 ~90%)
2. **공급자 교섭력** (TSMC·HBM 제조사에 대한 가격 결정력)
3. **고객 집중도** (하이퍼스케일러 4사 매출 비중)
4. **기술 해자** (CUDA 소프트웨어 생태계 락인)
5. **대체 위협** (AMD·브로드컴 ASIC의 침투 속도)

## 5. 카테고리 D: 예측·시뮬레이션 강화

### D1. ⭐⭐ What-If 시나리오 엔진 (확장판)

**현재 빈 곳**: 병목 시뮬레이터가 3개 고정 시나리오만 제공.

**제안**: 사용자가 **변수를 직접 조절**할 수 있는 시뮬레이션 엔진.

```
슬라이더 조절:
├── 하이퍼스케일러 Capex 증감률: [-30% ~ +50%]  ← 드래그
├── HBM4 수율: [30% ~ 90%]                       ← 드래그
├── TSMC CoWoS 월 캐파: [5만장 ~ 12만장]         ← 드래그
├── 데이터센터 전력 공급: [현 수준 ~ +50%]        ← 드래그
└── AI 모델 학습 수요 성장: [연 50% ~ 연 200%]    ← 드래그

→ 변수 조합에 따라 16개사 매출·영업이익 예측치가 실시간 변동
```

---

### D2. ⭐⭐ 컨센서스 추적 & 서프라이즈 탐지

**제안**: 증권사 컨센서스(예상치)와 실제 발표 실적의 **차이(서프라이즈)**를 추적.

| 기업 | 지표 | 컨센서스 | 실적 발표 | 서프라이즈 | 의미 |
| :--- | :--- | :---: | :---: | :---: | :--- |
| 엔비디아 | 매출 | $45B | $48B | **+6.7% 📈** | 수요가 예상보다 강함 |
| 삼성전자 | 영업이익 | ₩12조 | ₩10조 | **-16.7% 📉** | HBM4 수율 문제? |

**가치**: 서프라이즈가 발생하면 **기존 예측 테이블의 가정을 수정**해야 하는 신호.

---

### D3. ⭐ 몬테카를로 확률 시뮬레이션

**제안**: 미래 예측 테이블의 각 사건에 **확률 분포**를 부여하고, 수천 번 시뮬레이션하여 확률적 결과 제시.

```
삼성전자 2026 영업이익 예측:
├── 낙관 시나리오 (HBM4 수율 80%+): ₩58조 (확률 25%)
├── 기본 시나리오 (수율 60%): ₩48조 (확률 50%)  
└── 비관 시나리오 (수율 40% 이하): ₩35조 (확률 25%)

→ 기대값: ₩47.3조 ± ₩8.2조 (90% 신뢰구간)
```

## 6. 카테고리 E: 데이터 수집 확장

### E1. ⭐⭐⭐ 특허 출원 추적 (Patent Tracker)

**제안**: 각 기업의 **AI·반도체 관련 특허 출원 건수**를 시계열 추적.

| 데이터 소스 | 비용 | 접근 방법 |
| :--- | :---: | :--- |
| Google Patents | 무료 | `patents.google.com` 검색 + 스크래핑 |
| USPTO 공개 데이터 | 무료 | `patentsview.org` API |

**가치**: 특허 출원은 **제품 출시 1~3년 전의 선행지표**. 삼성전자의 HBM 관련 특허가 급증하면 차세대 HBM 준비가 가속화되고 있다는 증거.

---

### E2. ⭐⭐ 채용 공고 분석 (Job Posting Intelligence)

**제안**: 추적 대상 기업의 **AI·반도체 관련 채용 공고 수 변화**를 모니터링.

| 기업 | 2025 Q4 채용 공고 | 2026 Q2 채용 공고 | 변화 | 해석 |
| :--- | :---: | :---: | :---: | :--- |
| 엔비디아 "HBM" 포지션 | 45건 | 120건 | +167% | HBM 관련 팀 급확장 |
| TSMC "2nm" 포지션 | 200건 | 350건 | +75% | 2nm 양산 인력 확충 |

**가치**: 채용은 **투자 집행의 실행 지표**. Capex 가이던스는 계획이지만, 실제 사람을 뽑는 것은 실행.

---

### E3. ⭐ 공급망 리드타임 추적

**제안**: ASML EUV 장비 주문~인도 리드타임, TSMC 파운드리 슬롯 대기시간, HBM 주문~납품 리드타임 등을 추적.

## 8. 카테고리 G: 장기 진화 방향

사용자: "삼성전자가 HBM4로 2026년에 얼마나 벌 수 있어?"
