## 0. 현재 시각화 현황 (As-Is)

## 2. LLM 기반 요약 및 인사이트 자동 생성

### 2.1 💬 분기별 실적 Narrative Summary (자동 보고서)

**개요**: 매 분기 실적이 업데이트되면, LLM(Claude/Gemini)을 활용하여 **자연어 요약 보고서**를 자동 생성합니다.

**입력 데이터**: 
```python
# DB에서 추출하여 LLM 프롬프트로 전달
prompt = f"""
아래 {entity} 의 {period} 분기 실적을 분석해줘:
- 매출: ${revenue}B (전년 동기 대비 {yoy}% 변화)
- 영업이익: ${op_income}B (OPM: {opm}%)
- GPM: {gpm}%
- 컨센서스 대비: {beat_miss_status}
- 가이던스: {guidance_next_q}
- 핵심 사항: {key_takeaways}

밸류체인 맥락:
- 이 기업의 레이어: {layer}
- 주요 공급/수요 관계: {related_contracts}
"""
```

**출력**: 
```markdown
## NVIDIA 2026-Q2 실적 요약
NVIDIA는 $96.22B 매출을 기록하며 전년 동기 대비 +38% 성장했다. 
데이터센터 매출이 전체의 87%를 차지하며, Blackwell Ultra 수요가 
성장을 견인했다. SK하이닉스 HBM3E 공급 확대(2026-Q1 계약)가 
GPU 출하량 증대에 기여한 것으로 분석된다...
```

**구현 방식**: 
| 옵션 | 장점 | 단점 |
|:---|:---|:---|
| **A. 로컬 스크립트 + API** | 실시간, 맞춤 프롬프트 | API 비용 ($), 키 관리 |
| **B. 에이전트 대화형** | 대화형으로 즉시 활용 가능 | 수동 트리거, 재현성 낮음 |
| **C. 배치 보고서** | 정기 자동화 (월 1회) | 개발 비용 |

**추천**: **옵션 A (로컬 스크립트)** — `scripts/generate_quarterly_narrative.py`로 구현하여 `docs/generated/` 에 날짜별 Markdown 보고서 자동 저장.

## 3. 파생 정보(Derived Intelligence) — 실적 + 타 데이터 교차 분석

### 3.1 💡 HBM 단가 역산 분석

**활용 데이터**: `earnings_reports`(SK하이닉스/삼성 매출) + `financials`(HBM_REVENUE) + `fab_capacity`(HBM 생산능력)

**파생 지표**: 
```
HBM 추정 ASP = HBM_REVENUE / 추정 출하량(fab_capacity에서 역산)
HBM 비중 = HBM_REVENUE / 총 DRAM 매출
```

**가치**: *"HBM3E의 ASP가 분기별로 어떻게 변화하고 있는가?"* — 공개되지 않는 핵심 단가 정보의 간접 추정

---

### 3.2 💡 Capex → 매출 전환 효율(ROAI: Return on AI Investment)

**활용 데이터**: `financials`(CAPEX) + `earnings_reports`(REVENUE)

**파생 지표**:
```
ROAI = (t+4분기 매출 증분) / (t분기 Capex)
→ "AI에 $1B 투자할 때 4분기 후 매출이 얼마나 늘어나는가?"
```

| 기업 | 2024 Capex ($B) | 2025 매출 증분 ($B) | ROAI |
|:---|:---:|:---:|:---:|
| Google | 50.5 | +42 | 0.83 |
| Amazon | 72.7 | +55 | 0.76 |
| Meta | 39.2 | +28 | 0.71 |
| Microsoft | 55.7 | +35 | 0.63 |

**가치**: 하이퍼스케일러 간 **AI 투자 효율성 순위** 도출 → "어디에 투자하는 것이 가장 효율적인가?"

---

### 3.3 💡 밸류체인 매출 집중도 분석 (HHI 지수)

**활용 데이터**: `earnings_reports`(레이어별 기업 매출) + `contracts`(공급 관계)

**파생 지표**:
```
레이어별 HHI = Σ(시장점유율²)
→ HHI > 2500: 고도 집중 (독과점)
→ HHI 1500~2500: 중간 집중
→ HHI < 1500: 분산 경쟁
```

**분석 예시**: 
- **L3 컴퓨팅 HHI** ≈ 7,500+ (NVIDIA 독점적 지위)
- **L5 메모리 HHI** ≈ 3,500 (삼성-SK-마이크론 과점)
- **L2 하이퍼스케일러 HHI** ≈ 2,100 (상대적 분산)

**가치**: 밸류체인 내 **병목 지점(bottleneck)** 과 **교섭력 불균형** 식별

---

### 3.4 💡 실적 Beat/Miss 패턴과 주가 상관 분석

**활용 데이터**: `earnings_reports`(beat_miss_status, consensus_revenue, revenue) + 외부 주가 데이터(추후 연동)

**파생 지표**:
```
Beat Ratio = 연속 Beat 분기 수 / 전체 분기 수
Surprise Magnitude = (실제 매출 - 컨센서스) / 컨센서스 × 100
→ 서프라이즈 매그니튜드 vs 실적 발표 후 주가 변동률 상관 분석
```

**현재 가능 범위**: beat_miss_status 필드가 적재되어 있으나, 주가 데이터는 미보유 → **Phase 1에서는 Beat/Miss 패턴만 시각화**, 주가는 추후 Yahoo Finance API 연동

### 3.5 💡 기업 간 실적 선행지표 상관 매트릭스 (Leading Indicator)

**활용 데이터**: `earnings_reports` 17개사 분기별 매출

**파생 지표**:
```
상관계수 매트릭스: corr(Entity_A_Revenue[t], Entity_B_Revenue[t+lag])
→ lag = 0, 1, 2, 3분기로 교차 계산
→ 가장 높은 상관이 나오는 lag가 "선행 시차"
```

**분석 예시**:
```
NVIDIA Revenue[t] ↔ SK_HYNIX Revenue[t+1] → r = 0.92 (1분기 선행)
Google Capex[t]  ↔ NVIDIA Revenue[t+2]   → r = 0.88 (2분기 선행)
```

**가치**: *"NVIDIA 실적을 보면 1분기 후 SK하이닉스 실적을 예측할 수 있는가?"* → **투자 타이밍 시그널**

**구현 난이도**: ⭐⭐⭐ (Python pandas/numpy로 시차 상관 계산 → 히트맵 시각화)

| **D3.js** (v7) | ✅ Sankey에 사용 | Network Graph, Heatmap, Waterfall | 유연하지만 코딩량 많음 |

| **Observable Plot** | ❌ | 선언적 시각화 (빠른 프로토타이핑) | 대안 후보 |

### LLM 연동 옵션

| 방식 | 비용 | 장점 | 단점 |
|:---|:---:|:---|:---|
| **Claude API (Anthropic)** | $3~15/MTok | 긴 컨텍스트, 정교한 분석 | API 키 관리 필요 |
| **Gemini API (Google)** | $1.25~5/MTok | 저렴, Google 생태계 | 한국어 약간 약함 |
| **Local LLM (Ollama)** | 무료 | 오프라인 가능, 비용 없음 | GPU 필요, 품질 제한 |
| **에이전트 대화형** | 무료 | 이미 사용 중 | 자동화 불가, 수동 |

**추천**: 정기 보고서는 **Claude API**(품질 우선), 대시보드 인라인 코멘트는 **Gemini API**(비용 효율).
